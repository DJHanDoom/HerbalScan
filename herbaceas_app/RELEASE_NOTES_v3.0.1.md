# 🌿 HerbalScan v3.0.1 WIN - Correções na Interface

## 🐛 Correções Críticas

- ✅ **Interface do wizard corrigida** - Janela aumentada para 750x700 pixels
- ✅ **Botões visíveis** - Botões "Pular" e "Salvar e Continuar" agora aparecem corretamente
- ✅ **Layout otimizado** - Canvas de API keys reduzido para melhor visualização
- ✅ **Janela redimensionável** - Usuário pode ajustar o tamanho se necessário
- ✅ **Separator visual** - Adicionado separador antes dos botões para melhor organização

## 🔧 Melhorias Técnicas

- ✅ **Tratamento de erros robusto** - Sistema não falha mais se wizard não abrir
- ✅ **Fallback automático** - Cria .env básico se interface gráfica falhar
- ✅ **Logs de debug melhorados** - Mensagens mais informativas no console
- ✅ **Console persistente** - Mantém-se aberto em caso de erro (aguarda ENTER)

## 📦 O que está incluído

- Todas as funcionalidades da v3.0.0
- Correções na interface do wizard de configuração
- Melhorias no tratamento de erros

## 🚀 Como Atualizar

Se você já tem a v3.0.0 instalada:
1. Baixe a nova versão
2. Desinstale a versão anterior (opcional)
3. Instale a nova versão
4. Suas configurações serão preservadas
