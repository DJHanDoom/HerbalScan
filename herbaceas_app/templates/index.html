📖 Instruções de Uso

1️⃣ Configurar API Keys

Clique no ícone de configuração (⚙️) no canto superior direito e adicione suas chaves de API para os serviços de IA desejados (Gemini, Claude, GPT-4, etc.).

2️⃣ Criar ou Selecionar Parcela

Digite o nome da parcela no campo "Nome da Parcela" ou selecione uma parcela existente no menu dropdown.

3️⃣ Upload de Imagens

Clique em "Escolher Imagens" e selecione as fotos das subparcelas que deseja analisar. Você pode fazer upload de múltiplas imagens de uma vez.

4️⃣ Configurar Prompt (Opcional)

Utilize o painel de configuração de prompt para personalizar a análise. Você pode escolher templates predefinidos ou criar templates customizados.

5️⃣ Iniciar Análise

Selecione o modelo de IA desejado e clique em "🔍 Analisar". O sistema processará as imagens e identificará as espécies vegetais presentes.

6️⃣ Revisar e Editar Resultados

Após a análise, revise os resultados no painel lateral. Você pode editar espécies, coberturas, alturas e formas de vida conforme necessário.

7️⃣ Adicionar Espécies de Referência

Use o botão "📚 Espécies de Referência" para adicionar espécies ao banco de dados de referência, facilitando a padronização em análises futuras.

8️⃣ Exportar Dados

Utilize os botões no rodapé para exportar seus resultados em diferentes formatos:

  • 📊 Excel: Planilha completa com análises avançadas, índices de diversidade e rankings
  • 📄 PDF: Relatório visual com gráficos e tabelas
  • 📦 ZIP: Pacote completo incluindo JSON + imagens das subparcelas
9️⃣ Importar Projetos

Use "📥 Importar Projeto" para carregar análises anteriores salvas em formato ZIP.

🤖 Modelo de IA

🔑 Por que preciso configurar isso?

O HerbalScan não tem uma inteligência artificial própria - quem realmente olha suas fotos e identifica a vegetação é um serviço externo de IA (Google, OpenAI, Anthropic etc). Por isso você precisa de uma chave de acesso pessoal (API key) de pelo menos um desses serviços.

É rápido (menos de 2 minutos) e a maioria tem opção 100% gratuita pra começar. Sua chave fica guardada só no seu navegador, neste computador - nunca é enviada pra nós, e cada análise usa sua própria conta diretamente com o provedor escolhido.

Ou escolha outro provedor abaixo. Modelos Premium exigem uma API key paga; os Grátis funcionam com uma chave gratuita do provedor.
